# 応用情報技術者試験 科目B CBT模擬試験（非公式）

CBT方式の科目B試験の画面操作に慣れるための、非公式の練習用アプリです。専門学校の資格対策授業で、
考査・練習に使うことを想定しています。IPA・CBT-Solutions とは関係ありません。

画面の構成と操作は、CBT-Solutions が公開している「科目B群 試験当日の試験アプリ 操作方法のご案内」
（AP・NW・SC 向け）に合わせています。

## 現在の段階（①画面）

サーバーなしで動く試験画面です。`ap-cbt/index.html` を開くと使えます（ローカルなら `python3 -m http.server` で配信）。

- 試験一覧 → 問題選択 → 本試験 → 試験終了 → 解答例と見比べる（自己採点）
- 画面上部：残り時間、白黒反転、問題選択、メモ、参考資料、試験終了
- 問題文：拡大・縮小、マーカー（赤・青・黄、消しゴム、サイズ、クリア）、左右の枠の境目のドラッグ
- 解答欄：選択ボタン／複数選択／プルダウン／1行解答欄（字数・英数字制限）／複数行解答欄（検索・カット・コピー・ペースト、文字数表示）
- 設問ごとの「後で見直す」チェック、画面下部の「後で見直す」（大問の全設問にチェック）
- 解答状況（未解答・解答済み・後で見直すもの・解答中を色分け）、電卓（小・中・大）、問題（別画面）
- キー操作によるコピー・貼り付けは不可（本番の仕様）。解答・メモは端末に自動保存され、再読み込みしても続きから受験できる

### 出題設定（教員モードができるまでの暫定）

URL パラメータで出題を変えられます。

| パラメータ | 意味 | 例 |
|---|---|---|
| `exam` | 出題データ | `2025a`（令和7年度秋期） |
| `problems` | 出題する大問 | `problems=1,3,5,6` |
| `required` | 必須問題（空なら必須なし） | `required=1` |
| `select` | 解答する問題数（必須を含む） | `select=3` |
| `time` | 試験時間（分） | `time=60` |
| `review` | 終了後の解答例表示（`0` で無効） | `review=0` |

例：`index.html?problems=1,5,6&required=1&select=2&time=60`

## データ

- `data/2025a/img/` … IPA 公表の問題冊子 PDF を大問ごとのページ画像にしたもの（メモ用紙のページは除く）。`ref-*.png` は擬似言語の記述形式（参考資料）
- `data/2025a/exam.js` … 大問・設問と解答欄の種類・上限文字数の定義
- `data/2025a/answers.js` … IPA 公表の解答例。試験画面では読み込まず、終了後の見比べでだけ読み込む

問題・解答例の出典：独立行政法人情報処理推進機構（IPA）「令和7年度 秋期 応用情報技術者試験 午後」。
