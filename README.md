# ITサービスマネージャ試験 午前II 演習道場

ITサービスマネージャ試験の午前II対策のための、過去問道場スタイルの学習用Webアプリです。
ビルド不要のプレーンなHTML/CSS/JavaScriptで作られており、`index.html` をブラウザで開くだけで使えます。

IPA公表の実際の過去問（2009年度〜2025年度、2020年度は試験中止のため欠番）午前II問題を
全400問（各年度25問×16年度）を収録しています。
フローチャートやグラフなど図表が必須の問題（22問）も、該当ページの図版を画像として表示することで
そのまま出題できるようにしています。

## 機能

- **ランダム演習**: 全分野からランダムに指定問数を出題
- **年度別本番形式演習**: IPA公表の実際の過去問を、その年度の出題順のまま通しで演習（本番形式の腕試し）
- **分野別演習**: サービスマネジメント、インシデント管理、変更管理、可用性管理、ITサービス継続性管理、SLA、財務管理、セキュリティ管理、システム監査、プロジェクトマネジメント、テクノロジ系基礎等、分野を絞って出題
- **苦手問題の復習**: 直近の解答で不正解だった問題だけを再出題
- **全問通し演習**: 収録した全問題を順番に出題
- 解答するとその場で正誤と解説を表示（解説は選択肢ごとに改行され、誤答の理由にも言及）
- 1セットの演習後、不正解だった問題だけを全問正解するまで繰り返し再挑戦できる「周回モード」
- 結果画面で分野別正答率と間違えた問題の復習リストを表示
- 学習履歴（正答率・苦手問題）はブラウザの `localStorage` に自動保存され、次回起動時も引き継がれます
- 「達成度」画面で全体・分野別・年度別の習得率を確認、「学習履歴」画面で演習ログとヒートマップを確認
- 自分のGitHubアカウントの非公開Gistを使って、複数端末間で学習履歴を同期可能（後述）

## 収録している過去問について

- `data/past-exams.js`（`window.QUESTIONS_PAST`）に、IPA公表の実際の過去問を年度ごとに収録しています。
- 問題PDF・解答PDFをテキスト化した上で、OCR特有の文字化け（「エ」が「工」や「1」に誤認識される等）を
  ITサービスマネージャ試験・ITIL・JIS Q 20000等の専門知識で補正し、構造化しています。
- 解説（explanation）は簡潔な参考解説として生成したものです。内容の正確性については各自で公式資料等
  もあわせてご確認ください。
- フローチャートやネットワーク構成図、PERT図、グラフなど、視覚的な図が必須の問題（各年度0〜3問、
  合計22問）は、該当ページを画像化して `data/images/` に格納し、出題時に問題文と一緒に表示しています
  （`image` フィールドで参照）。

## 端末間の同期について

学習履歴は基本的にブラウザの `localStorage` に保存されるため、そのままでは同じ端末・同じブラウザでしか
引き継がれません。複数の端末（PC・スマホなど）で共有したい場合は、「達成度」画面の
「端末間の同期（任意）」から設定できます。

- **最初の1台だけ**: GitHubで `gist` 権限のみの個人アクセストークンを発行（有効期限は「No expiration」）して貼り付け、
  「同期を開始」を押します。自分のGitHubアカウントに非公開（secret）のGistが作られ、同期先になります。
- **2台目以降**: 1台目の「達成度」画面に表示される「他の端末をつなぐリンク」を、自分宛てのメッセージ等で送って
  開くだけです。GitHubへのログインもトークンの入力も不要です。リンクの設定は読み込み後すぐアドレスバーから消えます。
  （リンクには同期用の鍵が含まれるため、パスワードと同じ扱いで他人には共有しないでください。）
- 同期のたびに、ローカルとGist双方のデータを問題ごとに比較し、より新しい解答結果・より多い演習回数を
  採用してマージします。そのため、同期によって「習得済み」だった問題が「未学習」扱いに戻ることはありません。
- 解答するたびに（数秒後に）、またアプリを開き直した・開いたままの画面に戻ってきた時にも自動で同期され、
  表示中のホーム・達成度・学習履歴の数字もその場で更新されます（演習中の画面は書き換えません）。同期に失敗している間（トークンの期限切れなど）は、
  画面上部に警告が表示されます。「達成度」画面の「トークンを更新する」から新しいトークンを入力すれば復旧します。
- 共有端末では使用後に「この端末の同期を解除」しておくことをおすすめします。

## 使い方

ローカルで開くだけで動作します。

```
open index.html   # macOS の場合
```

もしくは簡易サーバーを立てて開いても構いません。

```
python3 -m http.server 8000
# http://localhost:8000/ にアクセス
```

GitHub Pages 等の静的ホスティングにもそのまま配置できます。

## 問題データの形式

問題データは `data/past-exams.js` の `window.QUESTIONS_PAST` 配列にあります。1問は次の形式です。

```js
{
  id: "PE-2025-01",              // 一意なID（学習履歴はこのIDで記録されます）
  year: 2025, session: "春期", qnum: 1,
  category: "サービスマネジメント全般", // 分野名（分野別演習の選択肢に自動で反映されます）
  question: "問題文",
  image: "data/images/PE-2025-06.png", // 任意。図表が必要な問題のみ
  choices: { ア: "選択肢1", イ: "選択肢2", ウ: "選択肢3", エ: "選択肢4" },
  answer: "イ",                  // 正解のキー
  explanation: "解説文"
}
```

学習履歴・達成度の母数は、この配列に含まれる問題だけです。

## ディレクトリ構成

```
ipa_study/
├── index.html          エントリーポイント
├── css/style.css       スタイル
├── js/app.js           アプリ本体（ルーティング・出題ロジック・localStorage管理）
├── data/past-exams.js  実際の過去問データ（window.QUESTIONS_PAST）
└── data/images/        過去問の図版画像（フローチャート・グラフ等）
```
