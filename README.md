# ITサービスマネージャ試験 午前II 演習道場

ITサービスマネージャ試験の午前II対策のための、過去問道場スタイルの学習用Webアプリです。
ビルド不要のプレーンなHTML/CSS/JavaScriptで作られており、`index.html` をブラウザで開くだけで使えます。

## 機能

- **ランダム演習**: 全分野からランダムに指定問数を出題
- **分野別演習**: サービスマネジメント、インシデント管理、変更管理、可用性管理、ITサービス継続性管理、SLA、財務管理、セキュリティ管理、システム監査、プロジェクトマネジメント等、分野を絞って出題
- **苦手問題の復習**: 直近の解答で不正解だった問題だけを再出題
- **全問通し演習**: 収録した全問題を順番に出題
- 解答するとその場で正誤と解説を表示
- 結果画面で分野別正答率と間違えた問題の復習リストを表示
- 学習履歴（正答率・苦手問題）はブラウザの `localStorage` に自動保存され、次回起動時も引き継がれます
- 「成績」画面で累積正答率・分野別正答率を確認、履歴のリセットも可能

## 使い方

ローカルで開くだけで動作します。

```
open index.html   # macOS の場合
```

もしくは簡易サーバーを立てて開いても構いません。

```
python3 -m http.server 8000
# http://localhost:8000/ にアクセス
```

GitHub Pages 等の静的ホスティングにもそのまま配置できます。

## 問題の追加方法

問題データは `data/questions.js` の `window.QUESTIONS` 配列にあります。以下の形式でオブジェクトを追加するだけで問題を増やせます。

```js
{
  id: "SM-999",                 // 一意なID
  category: "サービスマネジメント全般", // 分野名（分野別演習の選択肢に自動で反映されます）
  question: "問題文",
  choices: { ア: "選択肢1", イ: "選択肢2", ウ: "選択肢3", エ: "選択肢4" },
  answer: "イ",                  // 正解のキー
  explanation: "解説文"
}
```

> 収録している問題は、IPA公表の過去問そのものではなく、午前II試験の出題範囲（サービスマネジメント、
> システム監査、プロジェクトマネジメント、ファシリティマネジメント、コーポレートガバナンス等）に基づいて
> 作成したオリジナルの演習問題です。IPAが無料公開している実際の過去問PDFを参照しながら、上記のフォーマットで
> `data/questions.js` に追記していけば、本番形式の過去問演習アプリとして拡張できます。
