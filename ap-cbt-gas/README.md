# 応用情報 科目B CBT模擬試験システム（GAS版・新）

以前の GAS 版（`main.gs` / `index.html` / `css.html` / `js.html` / `output.gs`）を土台に、
受験画面を本番の CBT（科目B群の操作説明）に合わせたものに入れ替え、次の機能を追加したものです。

- 本番と同じ受験の流れ：ログイン画面（ユーザーID・パスワード）→ 氏名確認 → トップ画面（試験一覧・文字入力方式）→ 受験者向け チュートリアル → 本試験
- 学生名簿によるログイン者の特定（ログイン情報シートを配布。名簿のメールアドレスと Google アカウントも照合）
- 受験中の解答の自動保存と、再読み込み・別の端末からの再開
- 終了時刻のサーバー側管理、教員による時間延長・「受験中に戻す」
- 画面離脱（別タブへの切替・全画面解除）の回数記録
- 教員画面：実施状況、採点（設問ごとに受験者の解答を並べて○△×、記号の設問は自動採点）、成績出力
- 練習用の試験は、提出後に解答例と見比べられる（試験マスタの「解答例表示」が 1 のとき）
- 提出時に以前と同じ「回答ログ」形式でも記録し、解答控えメールも以前と同じ内容で送る

**今動いている以前のシステムには手を加えません。** 新しいスプレッドシートとデプロイで並行して動かし、
準備ができたら学生に案内する URL を切り替えてください。

## ファイル

| ファイル | 内容 |
|---|---|
| `Code.gs` | 入口（`doGet`）、マスタ読み込み、学生向け API（開始・自動保存・提出・解答例） |
| `Teacher.gs` | 教員向け API（実施状況・延長・採点・成績出力） |
| `Admin.gs` | スプレッドシートのメニュー、初期設定、解答例の取り込み、採点用ドキュメント出力 |
| `index.html` / `css.html` / `js.html` | 学生画面（試験一覧と CBT 試験画面） |
| `teacher.html` | 教員画面（URL の末尾に `?mode=teacher`） |
| `appsscript.json` | マニフェスト（ドメイン内公開・実行は自分） |

## 設置手順

1. **スプレッドシートを用意する**
   今のスプレッドシートを「コピーを作成」し、コピーから「回答ログ」シートを削除します（マスタ4枚を引き継ぎます）。
2. **スクリプトを貼る**
   コピーしたスプレッドシートで「拡張機能 → Apps Script」を開き、上の表のファイルを同じ名前で作って中身を貼ります
   （`.gs` はスクリプト、`.html` は HTML）。`appsscript.json` は「プロジェクトの設定 →『appsscript.json』マニフェスト
   ファイルをエディタで表示する」をオンにすると編集できます。
3. **初期設定**
   スプレッドシートを再読み込みすると「CBT模試」メニューが出ます。「初期設定（シート・列の追加）」を実行します。
   既存のマスタの内容は消えません。次が追加されます。
   - `設定` シート（画像URL・教員メール・解答控えメール・自動保存間隔など）
   - `学生名簿` シート（メールアドレス・クラス・番号・氏名）
   - `受験記録` シート（受験ごとに1行。解答・採点もここに保存）
   - `解答例取込` シート
   - 試験マスタに `区分`（考査／練習）・`対象クラス`・`公開開始`・`公開終了`・`解答例表示` 列
   - 小問マスタに `解答例`・`配点`・`備考` 列
4. **名簿を貼る**：`学生名簿` に学生のアカウントのメールアドレス・クラス・番号・氏名・フリガナを貼り、
   メニュー「ログイン情報を発行」でユーザーID・パスワードを作ります。「ログイン情報シートを作成」で、本番の
   ログイン情報シートのように切り離して配れる用紙（ドキュメント）ができます。
   本番のログイン画面を使わず Google アカウントだけで本人を特定したい場合は、`設定` の `ログイン画面` を 0 にします。
5. **解答例を取り込む**：別途お渡しした `解答例_令和4秋〜令和7秋.csv` の中身を `解答例取込` シートに貼り、
   メニュー「解答例を小問マスタに反映」を実行します。対応が取れなかった小問は `解答例_未対応` シートに出るので、
   小問マスタの `解答例` 列に直接入力してください。
6. **デプロイ**：Apps Script の「デプロイ → 新しいデプロイ → ウェブアプリ」で、次を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校のドメイン）内の全員**
   学生用 URL はそのまま、教員用は末尾に `?mode=teacher` を付けます（メニュー「教員画面のURLを表示」でも確認できます）。
7. **確認**：学生のテスト用アカウントで練習用の試験を受験し、教員画面に表示されることを確かめてから考査に使ってください。

## 試験マスタの新しい列

| 列 | 意味 | 例 |
|---|---|---|
| 区分 | `考査` または `練習`（空欄は練習）。考査は提出後も解答例を見せない | 考査 |
| 対象クラス | 受験できるクラス（カンマ区切り）。空欄なら全員 | SF1,SF2 |
| 公開開始・公開終了 | 試験一覧に出す期間（日時）。空欄なら制限なし | 2026/12/10 9:00 |
| 解答例表示 | 練習で、提出後に解答例と見比べられるようにするか（1/0） | 1 |

試験時間・解答する問題数・出題する大問は、以前と同じく `試験マスタ` と `試験大問リンクマスタ` で設定します
（選択区分 1＝必須、2＝選択）。考査の実施中に時間を延ばす場合は、教員画面の「実施状況」から延長します。

## 問題文の画像

問題文は IPA 公表の問題冊子をページ画像にしたもので、このリポジトリの `ap-cbt/img/<大問ID>/` に置いてあり、
`設定` シートの `画像URL`（jsDelivr 経由）から読み込みます。現在、令和4年秋〜令和7年秋の7回分（77問）があります。
画像がない大問は、以前と同じく大問マスタの `PDFファイルID` のPDFをドライブのプレビューで表示します（マーカーは使えません）。

## 小問マスタ → CBT の解答欄

| 小問マスタ | 試験画面 |
|---|---|
| 小問番号「設問3 a」「設問3 b」 | 「設問3」の中の空欄 a・b としてまとめて表示（解答状況も設問単位） |
| 選択（空欄記号あり） | プルダウン |
| 選択（空欄記号なし） | 選択ボタン |
| 多答（`3:ア,イ,…`） | 複数選択（3個まで） |
| 短答、制限なしの記述、15字以下の記述 | 1行解答欄（上限文字数） |
| 16字以上の記述 | 複数行解答欄（文字数表示・カット/コピー/ペースト/検索） |
| 図表、`（…）` で始まる制限 | 入力欄なし（注記を表示） |

## 本番の画面に合わせている点

CBT-Solutions 公開の「科目B群 試験当日の試験アプリ 操作方法のご案内」の画面に合わせています（IPA のロゴは使っていません）。

- ログイン画面、氏名確認（フリガナと氏名、OK／キャンセル）、トップ画面（ログアウト、白黒反転、注意事項、文字入力方式の選択と試し入力欄、試験一覧）
- 受験者向け チュートリアル（「確認終了」で終了、問題選択ボタンなし）
- 試験画面の見出しは `設定` の `試験画面タイトル`（既定「応用情報技術者試験 科目B試験」）と「○ページ中○ページ目」
- 確認ダイアログの文言（選択不足のとき「選択可能な問題数に対して，現在選択している問題数が不足しています。…」）
- 終了後はトップ画面（試験一覧）に戻る。得点は表示しない
- マーカーは細いペンの線（赤・青・黄、消しゴム、サイズ、クリア）。ツールボタンは紺色の四角
- 電卓は「± AC BS ÷ / 7 8 9 × / 4 5 6 − / 1 2 3 + / 0 00 . =」、大きさは「小・中・大」、閉じるのは「電卓」ボタン
- メモは半透明・ローマ字／かな・検索（検索行、件数、∧∨、一致箇所を黄色表示）・赤青黄のマーカーと消去・カット／コピー／ペースト・10,000字
- 問題（別画面）は緑のウィンドウ（大／標準、閉じる）

## 注意

- 自動保存は `設定` の `自動保存間隔(秒)`（既定 30 秒）ごとに、変更があったときだけ行います。変更がないときも終了時刻の確認は行います。
- 終了時刻を2分以上過ぎて届いた提出は、内容を採用せず、最後に保存された解答を正とします。
- 画面離脱の回数は目安です（ブラウザの通知や IME の候補ウィンドウでも数えることがあります）。
- Web アプリから画面を完全にロックすることはできません。考査では試験監督による確認と組み合わせてください。
